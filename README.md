# fin-posttrain

Post-training a small open LLM to summarize earnings-call transcripts:
QLoRA SFT → DPO → quantized vLLM serving. Built on
[ECTSum](https://github.com/rajdeep345/ECTSum) (EMNLP 2022).

**Status: work in progress.** This README only reports numbers that were
actually produced by the code in this repo.
